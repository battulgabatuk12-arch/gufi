## Монгол баатрууд 3.3 — Баатрын аян

Дээрээс харагддаг, Монгол ахуйгаас сэдэвлэсэн баатар болон цэрэг удирдах тоглоом.
Нэг HTML файлтай. Татаж авсан `index.html` файлыг Chrome, Edge, Firefox эсвэл Safari-д нээнэ.
Ганцаараа горим интернэтгүй ажиллана; нэмэлт сан, бүртгэл, суулгалт шаардахгүй.

### 3.3 хувилбарт нэмсэн

- **Баатраа шууд удирдах:** WASD / сумтай товч; утсанд дөрвөн чиглэлийн мэдрэгчтэй товч.
- **Хурдлах:** Space / ⚡ товч. 0.65 секунд 2.5 дахин хурдална, 8 секундийн дараа дахин бэлэн болно. Алт зарцуулахгүй.
- **Цэрэг дагуулах:** F / ⚑ товч. Өөрийн цэргүүд баатрыг дагаж, ойртсон дайсантай тулалдана.
- **Горим солих:** H / баатрын товч. Цэргийн горимд олон цэргийг сонгож газрын зурагт тушаал өгнө. Газрын зурагт хөдөлгөөний тушаал өгөхөд цэргийн горимд шилжинэ.
- Баатрын амин хүч, чадварын үлдсэн хугацаа, баатрыг дагах камер.
- Хадгалсан тоглолтын түвшин, хурдыг зөв сэргээнэ. Шинэ тоглолт 1× хурдтай эхэлнэ.
- Ганцаарчилсан тоглолтын табыг нуухад автоматаар хадгалж, завсарлана. Дахин нээгээд «Үргэлжлүүлэх» дарна.
- Гэмтсэн хадгалалт, буруу өрөөний өгөгдлийг шалгана. Олон тоглогч эхлэх үеийн дараалсан тушаалуудыг хүлээн авдаг болсон.

### Удирдлага

| Товч | Үйлдэл |
| --- | --- |
| WASD / сум | Баатрын горимд хөдөлгөх; цэргийн горимд зураг хөдөлгөх |
| H | Баатар / цэрэг удирдах горим |
| Space | Баатрын горимд хурдлах; цэргийн горимд цэрэг дээр төвлөрөх |
| F | Цэрэг дагуулах / зогсоох |
| 1 / 2 / 3 / 4 | Бүх цэрэг / морьт / харваач / баатар сонгох |
| 5 / 6 | Дайны уухай / суман бороо |
| X / P | Зогсох / түр завсарлах |
| Q / E | Зураг холдуулах / ойртуулах |

Ойртсон дайсантай автоматаар тулалдана. Баазын хамгаалагчдыг ялж, дэргэд нь 6 секунд байвал эзэлнэ.
Уурхайг 4 секунд хамгаалбал +55 алт, цаашид +4 алт/секунд авна.
13 баазаас 8-ыг эзлэхэд ялна; 12 минутын дараа хамгийн олон баазтай овог түрүүлнэ.

### Найзуудтай тоглох

1. Ижил **3.3** хувилбарыг нээнэ. Хоёр төхөөрөмжөөс тоглоход HTTPS дээр байршуулсан ижил хуудсыг ашиглавал тохиромжтой.
2. «Найзуудтайгаа» → хочоо бичээд «Өрөө нээх» дарна.
3. Найз нь 6 оронтой кодыг оруулаад «Нэгдэх» дарна.
4. Өрөөний эзэн «Тоглолт эхлүүлэх» дарна. Нийт 2–4 тоглогч; сул овгийг бот удирдана.

Өрөөний эзэн хуудсаа нээлттэй байлгана. Өрөөний төлөв нийтэд нээлттэй MQTT туршилтын relay
(`wss://broker.emqx.io:8084/mqtt`) дамжина; үйлчилгээний хүртээмжээс хамаарна.
Өрөөний хоч болон тоглолтын өгөгдөлд нууц мэдээлэл оруулахгүй.
Дахин холбогдож үргэлжлүүлэх, тусгай сервер болон нууц өрөөний баталгаажуулалт одоогоор байхгүй.

### Хөгжүүлэлт, шалгалт

Node.js 20 эсвэл түүнээс дээш хувилбарт:

```sh
npm test
```

Хамаарал татах шаардлагагүй. Engine болон UI-ийн логикийг Node-ийн `node:test` ашиглан шалгана.
`tests/ui-harness.cjs` нь хөтөч, интернэт ашиглахгүй DOM/MQTT орчин дуурайлган ажиллуулдаг.
Энэ нь CSS байрлал, бодит iPhone/Safari, бодит мэдрэгчтэй дэлгэц эсвэл нийтийн relay-ийн хүртээмжийг батлахгүй.

Нийт 21 шалгалтад хөдөлгөөн, диагонал хурд, орхигдсон тушаалын хугацаа, тулаан, хурдлах cooldown,
дагуул цэрэг, бааз/уурхай, хуучин хадгалалт, гэмтсэн өгөгдөл, 4×60 цэрэгтэй өрөөний packet,
ботын бүтэн тоглолт, утасны товчны event, хадгалалт/сэргээх болон хоёр тоглогчийн packet солилцоо багтсан.

### Файлууд

- `index.html` — тоглоом, зурсан дүрс, хөгжим, симуляци, өрөөний холболт.
- `tests/engine.test.cjs` — симуляци, хадгалалт, packet шалгалт.
- `tests/ui.test.cjs` — удирдлага, сэргээх, хоёр тоглогчийн логикийн шалгалт.
- `tests/ui-harness.cjs` — интернэтгүй туршилтын орчин.

Энэ салбар нь өмнөх `Mongol-Baatruud-3.2.zip` дээр суурилсан. Бодит хөтчийн харагдац болон
гаднын relay-гаар хоёр төхөөрөмж холбох туршилт хийх шаардлагатай хэвээр.
