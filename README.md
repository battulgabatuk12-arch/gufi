## Монгол баатрууд 4.3 — Сүлдийн аян

Монгол ахуйгаас сэдэвлэсэн, дээрээс харагддаг баатар/цэрэг удирдах тоглоом. iPhone, Android, компьютерт ажиллах суулгадаг PWA апп.

### Дүрслэл, аяны өгүүлэмж

Цэргийн хажуугийн самбарын **«Аяны тэмдэглэл · Дүрслэл»** хэсэгт хамгийн сүүлийн 8 өөрийн үйл явдал цагтайгаа харагдана. Бааз, уурхай, сургалт, цэрэг элсүүлэлт, улсын хөгжил, хамгаалалтын мэдээ уран өгүүлэмжийн хэд хэдэн хувилбараар ээлжилнэ. Үйл явдлын бодит тайлбар, алт, түвшин зэрэг тоо өөрчлөгдөхгүй. «Уран өгүүлэмж»-ийг унтраавал шууд мэдээлэл гарна. Шинэ аян болон хадгалсан аян нээхэд тэмдэглэл шинээр эхэлнэ.

Нарийвчилсан дүрслэлд өөрийн баатрын гэрэлт цагираг, амин хүчний нум, хөдөлгөөний чиглэл нэмэгдэнэ. **«Хөнгөн»** нь энэ нэмэлт дүрслэл, гэмтлийн тоо, тоосыг багасгана; таних цагираг хэвээр үлдэнэ. Сонголт төхөөрөмж дээр хадгалагдана. Өгүүлэмж, дүрслэлийн тохиргоо нь оноо, симуляци, эрэмбийн replay-д нөлөөлөхгүй. Өөр өөр төхөөрөмжөөс интернэтээр өрөөний кодоор нэгдэж тоглоно.

Баталгаажуулалт: `npm run build`, `npm test` — 49/49. Бодит iPhone touch, PWA суулгалт, хоёр төхөөрөмжийн интернэт relay-г гараар шалгах шаардлагатай. Энэ орчинд Chromium процесс socket зөвшөөрлөөр хаагдсан тул браузерын бодит зураглалын шалгалт хийгдээгүй.

### Улс, цэргийн хөгжил

Доод самбарын **«Улс»** товчоор хөгжүүлэлтийн цонх нээнэ. Бааз эзэлбэл +100 XP, уурхай эзэлбэл +60 XP, дайсан ялбал +10–20 XP авч улс 1–6 түвшин ахина. Улсын 1/2/3/4 түвшинд цэргийн сургалтын дээд түвшин 2/3/4/5 байна.

Сүлд баатар, морьт цэрэг, харваачийг тус тус алтаар сургана. Сургалт нь өөрийн одоогийн болон шинээр элсүүлэх тухайн төрлийн бүх цэргийн доод түвшинг өсгөнө. Түвшин бүр амин хүчийг +15%, цохилтыг +12% нэмнэ. Гэмтсэн цэргийн үлдсэн амин хүчний хувь хадгалагдана.

Цэрэг бүр тулааны цохилтоос +2 XP, дайсныг дуусгасан цохилтоос +12 XP, өөрөө оролцож эзэлсэн баазаас +20 XP, уурхайгаас +10 XP авна. 0/30/80/150/240 XP дээр 1–5 түвшинтэй болно. Сургалт өндөр түвшинтэй ахмад цэргийн туршлагыг бууруулахгүй. XP, түвшин, сургалт тухайн аяны хадгалалт болон найзуудын өрөөний snapshot-д орно. Шинэ аян түвшин 1-ээс эхэлнэ.

Утасны дугуй удирдлагын аль ч хэсгийг дарж чирэхэд хөдөлнө; диагональ чиглэл дэмжинэ. Нөгөө хуруугаараа хурдлах товч ашиглаж болно. Хуруугаа авах, цуцлах, цонх солих, цэс нээхэд хөдөлгөөн зогсоно. Үндсэн товчнууд 44–54px; хөгжүүлэх, цэрэг элсүүлэх, бааз бэхлэх боломж нэг цонхонд байна. Босоо болон хэвтээ дэлгэцийн удирдлага тусдаа байрлалтай.

Шинэ ranked тасалбар `rulesVersion: 2` хэрэглэнэ. Хуучин кэштэй клиент болон эхэлсэн тасалбарууд өмнөх дүрмээрээ серверт дахин тооцогдоно. Шинэ өрөө 4.2 тусдаа relay namespace хэрэглэдэг тул бүх тоглогч 4.2 хувилбар нээх шаардлагатай.

### Тоглож сурах

Эхний удаа «Тоглож эхлэх» дарахад гурван товч заавар гарна. «Заавартай тоглох»-ыг сонговол Хялбар түвшний дасгалын аян эхэлнэ.

1. Шар цагирагтай эхний бааз руу «Цэргээ бааз руу явуулах» дарж бүх цэргээ хамт явуулна. Камер цэргийг дагана; тулаан автоматаар явагдана.
2. Бааз эзлэх явцад хэдэн секунд үлдсэнийг харуулна. Баазыг эзэлсний дараа чулуун хэрэм болгож бэхлэхийг заана.
3. Дуусгаад баатраа гараар удирдах горимд эргэж орно. Дараагийн байн нэр, нөхцөл болон «Цэргээ явуулах» товч үргэлж харагдана.

Зааврыг алгасаж болно. «Яаж тоглох вэ?» болон тоглолтын ? товчоос дахин үзнэ. Овог, далбааны тохиргоо дэлгэгддэг хэсэгт орсон; үндсэн удирдлага, зорилго, товчны нэр том болсон. Эрэмбэтэй болон найзуудын аяны дүрэм өөрчлөгдөхгүй.

### Тоглох

HTTPS дээрх аппыг нээгээд «Аянд мордох» дарна. Дасгалын горим эхний удаа нээгдэж, офлайн файлууд хадгалагдсаны дараа интернэтгүй ажиллана. Найзуудын өрөө болон дэлхийн эрэмбэд интернэт шаардлагатай.

- **WASD / сум:** баатраа хөдөлгөх. Ойрын дайсантай автоматаар тулалдана.
- **Space:** 0.65 секунд 2.5× хурдлах. 8 секундийн дараа дахин ашиглана.
- **F:** цэрэг дагуулах / зогсоох.
- **H:** баатар / цэрэг удирдах горим. Цэргийн горимд WASD нь газрын зураг хөдөлгөнө.
- **B / Бэхлэх:** ойролцоох өөрийн баазыг бэхлэх. Эсвэл зурагт өөрийн баазыг товшиж сонгоно.
- **1–4:** бүх цэрэг / морьт / харваач / баатар сонгох.
- **5 / 6:** дайны уухай / суман бороо. **X / P:** зогс / түр завсарлах. **Q / E:** ойртуулалт.
- **Утас:** дугуй удирдлагыг дарж чирээд хөдөлгөнө; газрын зураг дээр нэг хуруугаар чирэх, хоёр хуруугаар ойртуулах. «Улс» товчоор цэргээ хөгжүүлнэ.

### Эзэмшлийн хамгаалалт

Баазын хамгаалагчдыг ялж, дэргэд нь 6 секунд байвал эзэлнэ. Шинээр эзэлсэн бааз автоматаар **260 амин хүчтэй модон хашаатай** болно. Эхлэх гэр бааз мөн хашаатай.

- Хашаагүй / нурсан баазад модон хашаа барих: **100 алт**.
- Модон хашааг **460 амин хүчтэй чулуун хэрэм** болгох: **160 алт**.
- Гэмтсэн хамгаалалтыг бүрэн засах: **40 алт**, 12 секундийн cooldown; 165 нэгжийн дотор дайсан байхгүй үед.
- Дайсны цэрэг хашааг нураасны дараа дотогш нэвтэрч баазыг эзэлнэ. Харваач хамгаалалтын дээгүүр тулалдана.
- Уурхайг 4 секунд хамгаалбал +55 алт, дараа нь +4 алт/секунд авна.
- 13 баазаас 8-ыг эзэлбэл ялна. 12 минутын дараа хамгийн олон баазтай овог түрүүлнэ.

### Дүр ба дүрслэл

Өөрсдөө Canvas-д зурсан нарийвчилсан хуяг, эмээл, хазаар, зэвсэг; 8 үе шаттай морины хөдөлгөөн; гурван өнгийн баатрын сүлд; цохилтын тоо, оч, уналтын эффект. Гаднын зураг, sprite pack, хөгжмийн бичлэг шаардахгүй. Хөгжим Web Audio синтезээр үүснэ.

### Эрэмбэ

«Эрэмбэтэй аян»-д хочоо бичиж орно. Хоч, RP, ялалтын тоо нийтэд харагдана. Хөтөч санамсаргүй профайл болон нууц түлхүүр үүсгэж дотроо хадгалдаг; бүртгэл/имэйл шаардахгүй. Профайл өөр төхөөрөмжид автоматаар шилжихгүй, хөтчийн өгөгдлийг устгавал профайлын эрх сэргээх боломжгүй.

Сервер аяны seed болон 24 цаг хүчинтэй тасалбар өгнө. Клиент 30 тогтмол алхам/секундээр ажиллаж, хүлээн авсан тушаалуудыг бүртгэнэ. Сервер дүн илгээхэд **ижил engine-ээр бүх аяныг дахин тоглуулж**, дууссан эсэх, хугацаа, тушаалуудыг шалгаж RP тооцно. Клиентээс явуулсан оноо, ялсан гэсэн утгыг ашиглахгүй.

RP = (ялалт 150, бусад дүн 20) + хэцүү түвшин 50 + бааз×12 + ялсан цэрэг×2 + min(бэхлэлт,20)×15, нэг аянд дээд тал нь 1000. RP нь улирлын хуримтлагдах оноо; Elo биш. Дасгалын болон найзуудын аяны дүн дэлхийн RP-д орохгүй. Дэлхийн ТОП-д бодит бүртгэлүүд л харагдана; тусдаа табад одоогийн аяны овгуудыг харьцуулна.

| Зэрэг | RP |
| --- | ---: |
| Шинэ дайчин | 0 |
| Хүрэл | 250 |
| Мөнгөн | 750 |
| Алтан | 1500 |
| Хөх чоно | 3000 |
| Их хаан | 6000 |

Эрэмбэ Vercel-ийн private Blob санд хадгалагдана. Conditional write / ETag нь зэрэг ирсэн дүнгээр бусдын оноог дарахаас хамгаална. Аяны ID бүрийг нэг удаа тооцно. Тасалбар, профайлын нууц түлхүүрийн hash л серверт хадгалагдана; тэдгээр нь дэлхийн жагсаалтад гарахгүй.

Энэ нь найзуудтай турших эхний улирлын ladder. Олон аккаунт үүсгэхээс бүрэн хамгаалсан тэмцээний систем биш. Тусгай серверийн олон тоглогчийн рейтинг, бүртгэл сэргээх, төхөөрөмж хооронд нэвтрэх боломж нэмээгүй.

### Апп суулгах

- **iPhone:** Safari → Share / Хуваалцах → **Add to Home Screen** → Add.
- **Android / компьютер:** аппын «Суулгах» товч эсвэл хөтчийн Install app цэс.
- App Store / Google Play-ийн native listing биш; HTTPS-ээр түгээгддэг PWA.

### Найзуудтай тоглох

«Найзуудтайгаа» → хоч → «Өрөө нээх». Найз нь ижил **4.2** апп нээгээд 6 оронтой кодоор нэгдэнэ. Өрөөний эзэн эхлүүлнэ, хуудсаа нээлттэй байлгана. 2–4 хүн; сул овгийг бот удирдана.

Туршилтын нийтийн MQTT relay (`wss://broker.emqx.io:8084/mqtt`) ашиглаж байгаа тул хүртээмжээс нь хамаарна. Өрөөнд хувийн нууц мэдээлэл оруулахгүй. Reconnect, өрөөний нэвтрэх баталгаажуулалт, тусгай multiplayer сервер одоогоор байхгүй.

### Хөгжүүлэлт ба нийтлэх

Node.js 20+:

```sh
npm install
npm run build
npm test
```

`npm run build` нь `index.html` дахь canonical engine-ээс `lib/engine.cjs` үүсгэж, PWA-ийн нийтийн файлуудыг `public/` руу хуулна. Engine-ийг зассаны дараа build ажиллуулна. Test-үүд SDK болон интернэтгүй ажилладаг; private Blob драйвер нь runtime-д `@vercel/blob`-ыг ачаална.

Vercel төсөлд холбосон private Blob store болон `BLOB_READ_WRITE_TOKEN` (эсвэл `BLOB_STORE_ID` + OIDC) шаардлагатай. Эдгээрийг source, manifest, service worker, browser bundle-д оруулахгүй. `vercel.json` нь статик файлууд, API, service worker-ийн cache header-уудыг тохируулна.

### Файлууд

- `index.html`: тоглоом, engine, дүр, UI, rank/PWA клиент.
- `api/rank.js`, `lib/rank-service.cjs`: эрэмбийн HTTP API, хадгалалт, баталгаажуулалт.
- `lib/engine.cjs`: build-ээр үүсэх серверийн engine; клиенттэй ижил эхтэй.
- `manifest.webmanifest`, `sw.js`, `icons/`: суулгах metadata, офлайн ажиллагаа, аппын дүрс.
- `tests/`: engine, UI/өрөө, эрэмбийн дахин тооцоолол, зэрэгцээ бичилт, PWA шалгалт.

Өмнөх 3.2, 3.3 болон 4.1 дасгалын хадгалалтыг уншиж хөгжүүлэлтийн талбаруудыг нэмнэ. Хуучин ranked хадгалалт өмнөх дүрмээрээ үргэлжилнэ. Автомат шалгалт нь хөдөлгөөн, сургалт/XP, хадгалалт, өрөөний дамжуулалт, зэрэгцээ эрэмбийн бичилт, серверийн replay, PWA shell-ийг хамарна. Browser QA нь 375×667, 430×900 болон 932×430 доторх дэлгэцийн layout, товчны hit target-ийг шалгана. Бодит iPhone/Android төхөөрөмжийн touch, native PWA суулгалт, хоёр төхөөрөмжийн нийтийн relay болон live ranked аяны бүтэн submit-ийг тусад нь гараар шалгах шаардлагатай.
